**Apa itu XML dan CSV?**

[XML](http://en.wikipedia.org/wiki/XML) (Extensible Markup Language) adalah bahasa markup dokumen, dan digunakan untuk representasi struktur data, seperti yang digunakan dalam layanan web. XML sering digunakan untuk pertukaran data melalui internet.

[File CSV](http://en.wikipedia.org/wiki/Comma-separated_values) (Comma/Character Separated Values) digunakan untuk menyimpan data tabular seperti teks & angka sebagai teks bidang. Data tabular dipisahkan dengan koma atau karakter lain. Ini banyak digunakan di berbagai bidang teknis, karena sangat membantu untuk memindahkan data tabular antar program.
