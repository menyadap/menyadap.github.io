**Faviconist.com** adalah generator Favicon online yang bagus. Ini menghasilkan Favicon menggunakan huruf. Pilih surat yang relevan dengan situs web Anda. Anda akan menemukan beberapa fitur pengeditan yang sangat keren seperti gaya font, opsi latar belakang baik dalam solid, gradien linier atau gradien radial, warna latar belakang, opsi latar depan baik dalam solid yang sama, gradien linier, atau gradien radial. Setelah setiap modifikasi, pratinjau akan ditampilkan. Anda dapat membuat Favicon Anda dengan mengklik tombol “Simpan Favicon”. Ini akan menghasilkan kode HTML yang dapat Anda gunakan dalam tag header Anda atau Anda cukup mengklik kanan gambar dan menyimpannya ke komputer Anda.

[Halaman Beranda](http://faviconist.com/)

## faviconmedia

## formito.com

Pembuat Favicon hebat lainnya adalah **formito.com** . Anda dapat menggambar Favicon sendiri atau mengunggah gambar apa pun dari komputer Anda. Anda dapat menambahkan warna pada latar belakang Favicon. Sesuaikan Favicon Anda dengan warna apa pun yang Anda inginkan dan gambarlah apa yang ingin Anda gambar dengan mengingat profil perusahaan dan bisnis Anda. Setelah Anda selesai dengan seluruh penyesuaian, unduh file gambar Favicon Anda ke folder root situs web Anda.

[Halaman Beranda](https://formito.com/tools/favicon)

## Konversi favic

[](https://listoffreeware.com/wp-content/uploads/2013/Faviconvert_fs_06052015.png)

[](https://listoffreeware.com/wp-content/uploads/2013/Faviconvert_fs_06052015.png)[

**Faviconvert.com** adalah situs web Favicon Generator yang cukup keren. Ini menghasilkan tiga jenis Favicon: dua file PNG dan satu file GIF animasi. Ukuran satu gambar adalah 32px, gambar kedua 16px, dan gambar lainnya animasi 16px. Situs web ini juga mendukung transparansi png. Cukup unggah gambar apa saja dari komputer Anda dan itu akan mengubahnya menjadi Favicon. Outputnya akan dalam paket zip. Paket zip akan berisi file readme yang menjelaskan cara menggunakan Favicon di situs web Anda.

[Halaman Beranda](http://www.faviconvert.com/)
