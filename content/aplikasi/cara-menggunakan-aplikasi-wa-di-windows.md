## Ini Aplikasi yang Bisa Digunakan Untuk Membuka WA di Windows ( Aplikasi WA PC Windows )

Tidak perlu menggunakan aplikasi pihak ketiga untuk menikmatinya,  [kini Aplikasi WhatsApp](https://www.wartangetop.com/tag/aplikasi)  dapat dinikmati di PC mulai dari windows 7 hingga seterusnya. Web resmi WhatsApp menuliskan aplikasi WA PC ini dapat digunakan untuk Windows 8 ke atas (64-bit) dan (32 bit). Selain itu dapat juga di install di MAC OS X 10.9.

Selain berfungsi sebagai alat komunikasi sehari-hari, ini WhatsApp dimanfaatkan juga untuk rapat, belajar dan kepentingan lain yang memanfaatkan fitur chat, group, dll. WhatsApp mempermudah penggunanya dengan meningkatkan fitur dan layanan yang diberikan. Mudahnya pengunduhan dan penggunaannya, banyak orang-orang yang sudah memanfaatkan aplikasi WhatsApp di PC.

Aplikasi apa yang dibutuhkan untuk membuka WA di PC yang menggunakan Windows 7? Cukup menggunakan browser seperti Google chrome atau Microsoft Edge dan masuk ke website resmi WA. Terdapat menu Whatsapp web, fitur, unduh, keamanan dan pusat bantuan, klik pada menu WhatsApp web untuk menggunakan WA di PC.

## Begini Cara Menggunakan Aplikasi WA PC Windows dengan Benar

Untuk menggunakan aplikasi WA PC di Windows 7 sangatlah mudah, cukup siapkan PC, koneksi internet dan ponsel. Lakukan 4 langkah praktis berikut untuk menggunakan aplikasi WA PC Windows 7 dengan benar:

### 1. Download Aplikasi WA di PC

Kunjungi  [situs resmi WhatsApp](https://www.wartangetop.com/tag/aplikasi)  dan cari kolom download atau ketikkan laman ini  [https://www.whatsapp.com/](https://www.whatsapp.com/)download. Pilih kapasitas bit sesuai dengan PC, terdapat 2 pilihan yaitu Download for Windows 8 64-Bit atau 32-bit sesuaikan dengan PC. Abaikan tulisan for windows 8 and higher karena aplikasi ini dapat juga di install pada windows 7.

### 2. Install Aplikasi WA PC atau Desktop

Cari aplikasi WA yang baru saja terunduh pada folder download atau unduh. Pilih Run as administrator dengan cara klik kanan di aplikasi WA yang baru saja terunduh. Selesaikan hingga instalasi selesai dengan sempurna yang kurang lebih memakan waktu 5 menit.

### 3. Buka Aplikasi yang Telah Terinstall

Pastikan aplikasi WA sudah terinstall dengan sempurna. Cari aplikasi WA yang sudah terinstall dengan mengklik ikon windows dan cari Whatsapp. Pilih open pada aplikasi WA yang sudah terpasang atau untuk cara pintas klik dua kali untuk membuka. Maka  [**aplikasi WA PC**](https://www.wartangetop.com/tag/aplikasi)  untuk windows 7 sudah bisa digunakan.

### 4. Sambungkan dengan ponsel

Setelah membuka Buka aplikasi WA di ponsel > pilih menu settings > linked devices. Kemudian akan muncul pemindai QR code. Pindai QR code yang ada di layar PC menggunakan ponsel dengan cara mendekatkan kamera ponsel ke layar PC. Kini ponsel dan PC sudah.
