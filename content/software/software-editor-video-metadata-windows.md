## abcAVI Penyunting Tag

**abcAVI Tag Editor** adalah **editor metdata video gratis** yang hanya mendukung format video AVI. Ini dirancang khusus untuk mengedit tag video dalam video AVI. Ini memungkinkan Anda mengedit informasi metadata (di tab *Tag AVI* ) yang meliputi:

1. **Tag Utama** : Di bagian ini, Anda dapat mengubah judul, sutradara, hak cipta, produk, genre, genre kedua, subjek, kata kunci, komentar, dan tanggal pembuatan.
2. **Kredit Film** : Anda juga dapat menambahkan kredit film ke video Anda dengan menambahkan informasi seperti 'ditulis oleh', 'diproduksi oleh', 'diedit oleh', sinematografer, 'musik oleh', produksi, dibintangi, rating (G, PG, R, dll.), negara, dll.
3. **Tag Tambahan** : Ini termasuk metadata seperti **Digitalisasi** (perangkat lunak, 'didigitalkan oleh', URL internet, 'dikodekan oleh', dll.), **Sumber** (bentuk sumber, sumber, media, dan lokasi), dan *Informasi Tambahan.*
4. **Tag Lainnya** : Memungkinkan Anda menambahkan URL logo, URL tanda air, URL gambar spanduk, dimensi, ketajaman, kecerahan, dll.

Anda dapat menggunakan opsi ' *Simpan Perubahan* ' (atau tekan *Ctrl+S* ) untuk menyimpan metadata yang diedit.

abcAVI Tag Editor memungkinkan Anda mengedit informasi dasar dan tambahan tentang video. Mendukung tag RIFF INFO, MovieID, dan IDivX. Anda juga dapat menggunakannya untuk melihat informasi terkait video. Ini juga memungkinkan Anda menyesuaikan preferensi antarmuka.

## FFMPEG

**FFMPEG** adalah alat 'utilitas video' baris perintah untuk Windows. Ini memungkinkan Anda mengedit metadata video dengan menjalankan perintah yang diperlukan.

### Untuk Mengedit Metadata Video dari Command Prompt Menggunakan FFMPEG:

1. 1. Buka command prompt di desktop Anda dan arahkan ke folder FFMPEG.
   2. Sekarang di command prompt, Anda dapat menggunakan sintaks untuk mengedit jenis metadata tertentu.
   3. Misalnya, jika Anda ingin mengedit judul video Anda, sintaksnya adalah: ffmpeg -i <nama dan jalur video> -metadata title=”value” -codec copy <nama dan jalur video>
   4. Perintah terakhir akan terlihat seperti ini:

`ffmpeg -i lof.mp4 -metadata title="List of Freeware" -codec copy lof.mp4`

Selanjutnya, ia akan meminta izin Anda untuk menimpa file. Cukup ketik ' *y'* dan jalankan perintah. Judulnya akan diubah. Demikian pula, Anda dapat mengedit informasi lain seperti artis, genre, trek, album, komentar, dll. Anda dapat melihat dokumentasi terperinci [untuk pengeditan tag video](http://ffmpeg.org/ffmpeg.html#Main-options "Sintaks Metadata FFMPEG") untuk lebih memahami sintaksis yang benar.

FFMPEG memungkinkan Anda melakukan berbagai operasi terkait video seperti [rotasi video](https://listoffreeware.com/free-video-rotator-software-windows/ "Rotasi Video di FFMPEG") , [pengubahan ukuran video](https://listoffreeware.com/free-video-resizer-software-windows/ "Mengubah Ukuran Video di FFMPEG") , dll. Ini juga mendukung berbagai format video.

## Pemutar media VLC

**Pemutar media VLC** adalah pemutar media populer yang dapat digunakan sebagai editor metadata video. Ini memungkinkan Anda mengedit dan menyimpan informasi tentang video Anda.

### Untuk Mengedit Metadata Video di pemutar media VLC:

* Buka video, buka menu *Tools >* *Media Information* atau cukup tekan hotkey ' *Ctrl + I* '.
* Sekarang, Anda dapat melihat informasi metadata terkini seperti detail umum, codec, statistik, dll.
* Anda dapat mengedit metadata umum video seperti *judul, artis, genre, album, hak cipta, penerbit, tanggal, nomor trek, komentar, bahasa,* dll .
* Setelah mengedit informasi ini, klik opsi *Simpan Metadata* . Perubahan yang Anda buat akan disimpan.

Jadi, inilah cara Anda memanfaatkan pemutar media VLC sebagai editor tag video. Karena mendukung berbagai format video, Anda dapat mengedit tag dasar di banyak video.
