## Penyingkat url massal

**Penyingkat url massal** adalah **perangkat lunak penyingkat URL massal gratis** untuk Windows. Dengan menggunakan perangkat lunak ini, Anda dapat dengan mudah mengecilkan URL beberapa situs web atau halaman web sekaligus. Untuk memperpendek URL, penyingkat URL ini menggunakan berbagai layanan bernama **TinyURL** , **adf.ly** , **macf.ee** , **is.gd** , **bit.do** , **mrcly** , dan **tiny.cc** . Semua layanan lainnya tidak berfungsi atau menghasilkan URL yang tidak mengarah ke situs web atau laman web yang dituju.

**Cara memperpendek beberapa URL menggunakan pemendek url massal:**

* Langkah pertama adalah menambahkan URL yang panjang. Untuk melakukan itu, Anda dapat menempelkan daftar URL panjang pada **bidang URL untuk mempersingkat** atau Anda dapat mengimpor beberapa URL yang terdapat dalam file **DAT dengan menekan** **tombol Impor URL** .
* Setelah itu tekan **tombol Shorten** untuk memulai proses pemendekan URL.

Setelah selesai, Anda dapat melihat semua URL yang baru dibuat di antarmuka. Anda juga dapat menyimpan daftar URL singkat yang baru dibuat dalam file **CSV** .

## Massal-goo.gl-lebih pendek

**Bulk-goo.gl-shorter** adalah penyingkat URL massal open source gratis lainnya untuk Windows. Ini adalah perangkat lunak berbasis web yang memerlukan perangkat lunak hosting seperti **XAMPP** , **WAMP** , dll. dan internet agar dapat berfungsi. Penyingkat URL ini juga menggunakan **Google API** untuk mengubah URL panjang menjadi lebih pendek. Namun, Anda harus mengunduh dan menempelkan **kunci API** terlebih dahulu ke file **index.php** perangkat lunak ini. Anda dapat mengunduh kunci API dari [tautan](https://developers.google.com/url-shortener/v1/getting_started#APIKey "Unduh Kunci Google API") ini .

Untuk meluncurkan perangkat lunak ini, pertama-tama jalankan modul **Apache** dan **MySql** dari XAMPP atau WAMP. Setelah itu, luncurkan browser dan tulis **localhost/index.php** (path lengkap file index.php). Sekarang, Anda dapat melihat *halaman Bulk-goo.gl-shorter* dengan *kolom* untuk memasukkan beberapa URL panjang. Tempelkan semua URL panjang ke kolom dan tekan **tombol Pendek Semua** untuk mendapatkan semua URL pendek terkait dari URL panjang yang dikirimkan.

Perangkat lunak ini tidak memiliki opsi untuk menyimpan URL pendek yang dihasilkan. Oleh karena itu, Anda perlu menyalin setiap URL secara manual untuk menyimpan atau membagikannya.
