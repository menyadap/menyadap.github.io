6 Software Spreadsheet Open Source Gratis Terbaik Untuk Windows

Berikut adalah daftar **Software Spreadsheet Open Source Gratis Terbaik** Untuk Windows. Ini adalah perangkat lunak yang memungkinkan Anda membuat dan mengedit spreadsheet. Semua perangkat lunak ini gratis dan open source. Artinya Anda mendapatkan kode sumber perangkat lunak spreadsheet ini yang dapat diunduh, dipelajari, dan bahkan dimodifikasi. Jadi, baik programmer maupun orang umum bisa menggunakan pembuat spreadsheet ini.

Perangkat lunak ini memungkinkan Anda menentukan tata letak spreadsheet seperti jumlah baris dan kolom, ukuran grid, margin, orientasi, dll. Anda dapat secara manual menambahkan kumpulan data ke spreadsheet atau mengimpor konten dari file seperti CSV, teks yang dibatasi tab, dll *.* Lainnya selain teks sederhana, Anda dapat menyisipkan *gambar, bentuk, hyperlink, tanggal & waktu, clipart,* dan lainnya ke spreadsheet. Plus, beberapa perangkat lunak ini berisi perpustakaan ***fungsi matematika*** bawaan untuk ditambahkan, misalnya, *Operasi Bitwise, Kompleks, Teknik, Logika, Teori Bilangan, Bilangan Acak, String,* dll.

Sebagian besar software ini juga bagus untuk ***visualisasi data*** dengan menggunakan berbagai grafik, seperti *batang, garis, area, pai, sebar, plot kotak, radar, permukaan,* dll. Salah satu software ini juga menyediakan berbagai algoritma untuk menghitung kumpulan data seperti *Statistik Deskriptif, Pengambilan Sampel, Pengamatan Ketergantungan, Uji Satu Sampel,* *Uji Dua Sampel,* dll.

Anda mendapatkan semua opsi pemformatan standar dalam perangkat lunak ini seperti font, ukuran, warna teks, warna latar belakang, dll. Selain itu, opsi untuk mengurutkan, menerapkan filter, dan banyak lagi ada di semua perangkat lunak ini. Perangkat lunak ini berfungsi baik dengan format spreadsheet populer termasuk XLS, XLSX, ODS, CSV, dll.

## Kalkulator LibreOffice

**LibreOffice Calc** adalah salah satu **perangkat lunak spreadsheet sumber terbuka terbaik** untuk Windows serta platform lain termasuk Mac dan Linux. Ini adalah bagian dari LibreOffice yang merupakan perangkat lunak perkantoran terkenal. Anda mendapatkan lebih banyak aplikasi perkantoran dalam suite ini termasuk **Writer** , **Draw** , **Impress** , **Math** , dan **Base** .

Ini memungkinkan Anda membuat, mengedit, dan mengelola berbagai spreadsheet. Untuk membuat atau mengedit spreadsheet, ia menyediakan berbagai alat termasuk *menyisipkan sel, menyisipkan baris, menyisipkan kolom, menyisipkan lembar dari file,* dll. Anda dapat memasukkan sejumlah elemen ke spreadsheet seperti *gambar, ikon* (dari galeri bawaannya) , *audio, video, bentuk, kotak teks, bingkai mengambang, hyperlink, tanggal dan waktu, header dan footer,* dll. Anda dapat memformat elemen yang ditambahkan dan menerapkan gaya tertentu ke spreadsheet menggunakan opsi seperti *opsi font, spasi, perataan, balik, menggabungkan sel,* dll. Setelah selesai membuat spreadsheet, Anda dapat menyimpannya sebagai *XLS, XLSX, HTML, CSV,* dll.

### Fitur yang harus diperhatikan dalam perangkat lunak spreadsheet sumber terbuka ini: LibreOffice Calc

* Ini menyediakan **Wizard Fungsi** yang berisi sejumlah besar fungsi matematika untuk digunakan dalam penghitungan kumpulan data.
* Ini dapat digunakan sebagai **[perangkat lunak visualisasi data](https://listoffreeware.com/free-data-visualization-tools-windows/ "LibreOffice Calc sebagai Alat Visualisasi Data")** untuk menghasilkan grafik untuk kumpulan data yang dimasukkan, misalnya *Diagram Garis, Diagram Lingkaran, Diagram Gelembung,* *Diagram Batang, Diagram Sebar, Diagram Kolom, Diagram Bersih, Diagram Saham,* dll .
* Anda dapat **melindungi** spreadsheet Anda dengan kata sandi dan **menambahkan tanda tangan digital** ke dalamnya.
* Alat tambahan seperti **Spellcheck, AutoCorrect Options, Share Spreadsheet, Solver** (menyelesaikan masalah optimasi), dll, juga tersedia di dalamnya.
* Di menu Data, Anda dapat menemukan opsi berguna seperti ***Sortir, Hitung, Validitas, Filter Standar, Filter Lanjutan, Tabel Pivot, Subtotal, Konsolidasi,*** dll .
* Itu dapat menangani sejumlah format input dan output seperti *XLS, XLSX, HTML, CSV, DIF,* dll .
* Anda dapat mengerjakan beberapa spreadsheet sekaligus karena antarmuka multi-tabnya.

## Gnumerik

**Gnumeric** adalah perangkat lunak spreadsheet sumber terbuka lainnya untuk Windows. Ini memungkinkan Anda membuat atau mengedit spreadsheet dalam format seperti XLS, XLSX, ODS, dll.

### Fitur utama perangkat lunak spreadsheet sumber terbuka ini:

* Anda dapat memformat sel dengan menentukan pengaturan seperti kategori (angka, mata uang, akuntansi, teks, pecahan, persentase, dll.), perataan, font, batas, latar belakang, dll. Ini juga menyediakan opsi seperti pemformatan sel bersyarat, menggabungkan sel, *memisahkan sel,* dll. Selain itu, Anda mendapatkan opsi untuk memformat teks, kolom, baris, dll.
* Anda dapat menyisipkan konten seperti *gambar, tanggal & waktu, nama, komentar, hyperlink,* dll.
* Ini juga berisi perpustakaan berbagai macam **fungsi** yang digunakan untuk evaluasi data, seperti *Operasi Bitwise, Kompleks, Teknik, Logika, Matematika, Teori Bilangan, Bilangan Acak, String,* dll.
* Anda mendapatkan berbagai bagan visualisasi data untuk menganalisis kumpulan data, seperti *Area, Batang, Gelembung, Kolom, Kontur, Pai, Radar, Permukaan, Cincin, DropBar,* dll .
* Ini menyediakan menu **Statistik** untuk tujuan perhitungan. Berisi metode perhitungan antara lain **Statistik Deskriptif** (Korelasi, Kovarian, Tabel Frekuensi, Peringkat & Persentil), **Pengambilan Sampel** , **Pengamatan Ketergantungan** (Perkiraan, Analisis Fourier, Estimasi Kaplan-Meier, Analisis Komponen Utama, Regresi), **Uji Satu Sampel** , **Uji Dua Sampel** , dan **Tes Beberapa Sampel** .
* Alat seperti *Koreksi Otomatis, Pencarian Sasaran, Solver, Simpan Otomatis,* dll., juga tersedia di dalamnya.
* Ini memberikan opsi untuk mengurutkan data, memfilter kumpulan data, mengacak data, memvalidasi data, mengkonsolidasikan data, dll.
* Anda dapat mengimpor data dari file eksternal seperti CSV, TSV, HTML, XLS, dll.
* Ini memberikan beberapa opsi yang lebih berguna seperti *menghitung ulang, mencari & mengganti, opsi tampilan,* dll.

Secara keseluruhan, saya sangat menyukai perangkat lunak ini karena cukup mudah digunakan dan menyediakan semua alat penting untuk mengatur, menyimpan, dan menganalisis kumpulan data.

## Lembar Pohon

**TreeSheets** adalah perangkat lunak spreadsheet open source gratis berikutnya untuk Windows, Mac, dan Linux. Ini adalah pembuat spreadsheet hierarki yang juga bertindak seperti pemetaan pikiran. Anda dapat menentukan ukuran kisi spreadsheet Anda dan kemudian mulai menambahkan konten teks atau kumpulan data numerik ke dalamnya. Selain membuat spreadsheet baru, ini memungkinkan Anda mengimpor dan mengedit file spreadsheet seperti CSV, teks yang dibatasi tab, XML, dll. Setelah selesai membuat spreadsheet, ini hanya memungkinkan Anda menyimpannya dalam format file asli atau memungkinkan Anda mengekspor tampilan spreadsheet sebagai file seperti CSV, HTML, Gambar, XML, skrip JSON, dll.  

Ini memungkinkan Anda menambahkan teks dan gambar ke spreadsheet. Anda dapat memformat teks dengan berbagai opsi penyesuaian seperti ukuran, font, warna, gaya, dll. Ini berisi lebih banyak opsi untuk penyesuaian spreadsheet seperti *Reorganisasi Grid, Tata Letak & Gaya Render, Atur Lebar Batas Grid,* dll. Hal baik lainnya adalah Anda bisa bekerja pada banyak spreadsheet di dalamnya karena memiliki antarmuka multi-tab. Jadi, ini adalah alternatif yang layak untuk perangkat lunak spreadsheet.

## penyebaran

**Pyspread** adalah salah satu perangkat lunak spreadsheet sumber terbuka gratis dalam daftar ini. Ini memungkinkan Anda membuat spreadsheet baru dari awal atau mengedit spreadsheet yang ada dalam format CSV. Anda juga dapat mengekspor spreadsheet sebagai file PDF atau SVG.

Anda dapat secara manual menambahkan kumpulan data ke spreadsheet dan memformat teks menggunakan opsi seperti *pemformatan font, tebal, miring, garis bawah, pembenaran, perataan, warna teks, warna latar belakang,* dll. Ini juga memungkinkan Anda menyisipkan file bitmap, menautkan file bitmap, menyisipkan bagan (bar, plot, pie, contour, Sankey, boxplot, dll.), dll. Selain itu, Anda dapat menyisipkan lebih banyak baris dan kolom, menghapus baris dan kolom, mencari dan mengganti teks, memeriksa ejaan, dll. Beberapa opsi lagi untuk *dipilih tata letak batas, lebar batas, warna garis batas, latar belakang sel, rotasi teks sel, pengurutan sel,* dll, ada di software ini.

**Catatan:** Ingatlah bahwa Anda harus menginstal Gpg4win terlebih dahulu (dari [sini](https://files.gpg4win.org/) ) di sistem Anda agar Pyspread dapat berfungsi. Ini berisi instruksi yang tepat pada halaman unduhannya yang dapat Anda checkout dari tautan di bawah.
