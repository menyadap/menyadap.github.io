## Xpdf

**Xpdf** adalah perangkat lunak pengekstrak font PDF lainnya untuk Windows. Ini adalah perangkat lunak baris perintah yang dapat Anda gunakan melalui command prompt untuk menjalankan berbagai tugas terkait PDF, salah satunya mungkin termasuk ekstraksi font PDF. Selain mengekstrak font dari PDF, ini juga memungkinkan Anda melakukan tugas seperti melihat informasi PDF, mengekstraksi gambar PDF, mengonversi PDF menjadi teks, mengonversi PDF ke HTML, dll.

### Cara mengekstrak font dari PDF menggunakan perintah:

Untuk menemukan font yang digunakan dalam PDF dengan cepat, Anda perlu mengikuti langkah-langkah di bawah ini:

* Pertama, salin dan tempel file PDF sumber ke folder unduhannya > subfolder bin64 atau bin32 (sesuai konfigurasi sistem Anda).
* Sekarang, buka command prompt dan arahkan ke folder bin64 atau bin32 perangkat lunak ini.
* Selanjutnya, tulis perintah seperti: `pdffonts.exe 1.pdf`. Di sini, 1.pdf adalah file PDF masukan yang ingin Anda ekstrak fontnya. Anda juga dapat memberikan PDF yang disimpan di lokasi lain hanya dengan memasukkan jalurnya.
* Terakhir, tekan Enter dan segera setelah Anda melakukannya, daftar semua font yang digunakan dalam PDF sumber akan ditampilkan. Ini menunjukkan nama font, jenis, font yang disematkan, dan informasi lebih lanjut.

Seperti namanya, pada dasarnya ini mengekstrak data dari dokumen PDF yang mencakup informasi font, warna, kotak, dan OCG. Ini adalah ekstraktor font PDF berbasis web, jadi Anda memerlukan browser web untuk menjalankan aplikasi ini. Mari kita lihat bagaimana Anda dapat mengekstrak font menggunakan perangkat lunak berbasis web gratis ini.

### Cara mengekstrak font dari PDF di PDF Data Extractor:

* Pertama, ekstrak folder downloadnya dan buka file *index.html* di browser web.
* Sekarang, masukkan dokumen PDF di bidang File-nya.
* Segera setelah Anda memberikan file PDF, itu akan menampilkan kode JSON dengan nomor halaman dan Font yang digunakan.

### Fitur Tambahan:

Anda dapat menyimpan data yang diekstraksi dari PDF termasuk font dalam file JSON lokal.
