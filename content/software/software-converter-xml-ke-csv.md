[XML](http://en.wikipedia.org/wiki/XML) (Extensible Markup Language) adalah bahasa markup yang menetapkan parameter untuk menyandikan dokumen dalam format yang dapat dibaca Manusia & Mesin. XML sering digunakan dalam pertukaran informasi di berbagai bidang, seperti sains, teknologi, penelitian, IT, dll. File XML dapat dengan mudah membawa data tabular di dalamnya, dan membantu transportasi data yang efisien dalam suatu program. [CSV](http://en.wikipedia.org/wiki/Comma-separated_values) (Comma/Character Separated Values) menyimpan informasi tabel stok, seperti teks & angka. Data ini dipartisi berdasarkan koma, atau karakter. Karena membantu membawa data tabular antar program, ia memiliki kegunaan yang luas di berbagai bidang teknis.

Sederhananya, dengan mengonversi file XML ke file CSV, kami mengekstraksi data tabel dari XML. Jika kita ingin memasukkan data tabel kembali ke XML, kita perlu melakukan konversi CSV ke XML. Selain XML, file CSV juga dapat dikonversi ke bahasa markup dokumen lainnya.
