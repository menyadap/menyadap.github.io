## Peramban Tor

**Tor Browser** adalah perangkat lunak klien VPN sumber terbuka gratis untuk Windows, macOS, Linux, dan Android. Sesuai dengan namanya, ini adalah browser web yang memiliki klien VPN sendiri yang memungkinkan pengguna menjelajahi web secara anonim. Untuk menyembunyikan identitas Anda dari internet, klien VPN ini menggunakan **jaringan Tor** yang terdiri dari ribuan node dan jembatan. Setiap node mengambil data dan meneruskannya ke node mana pun yang dipilih secara acak untuk memblokir pelacakan. Tidak seperti perangkat lunak VPN serupa lainnya, perangkat lunak ini tidak menyediakan dukungan VPN ke seluruh sistem Anda.

Berikut adalah fitur utama klien VPN sumber terbuka ini:

### Fitur utama:

* **Blokir Pelacak** : Fitur ini memblokir semua jenis pelacak yang digunakan situs web untuk menampilkan iklan yang relevan kepada Anda. Plus, secara otomatis menghapus semua cookie segera setelah Anda menutup perangkat lunak ini.
* **Pertahanan Terhadap Pengawasan** : Ini juga mencegah Anda dari pengawasan yang bertujuan untuk mengetahui situs web yang sering Anda kunjungi.
* **Resist Fingerprinting** : Fitur ini melindungi pengguna agar tidak terdeteksi oleh berbagai algoritma dan peretas.
* **Enkripsi Berlapis** : Semua lalu lintas yang melewati jaringan Tor dienkripsi tiga kali.

### **Fitur Tambahan** :

* **Add-on** : Dalam perangkat lunak ini, Anda juga dapat menambahkan add-on dan ekstensi browser untuk meningkatkan rangkaian fiturnya.
* **Perpustakaan** : Dengan menggunakannya, Anda dapat mengelola *bookmark, riwayat,* dan *unduhan* .
* **Kustomisasi** : Memungkinkan Anda menambahkan berbagai pintasan seperti *menu tambahan, riwayat, mode layar penuh,* dll. melalui antarmuka utama.
