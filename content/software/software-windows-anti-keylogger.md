## Pengaya Firefox: Pemukul Keylogger

[](https://listoffreeware.com/wp-content/uploads/keyloggerbeater_large_2016-10-21_17-59-13.png)

**Keylogger Beater** bukanlah *program anti-keylogger* tetapi memungkinkan Anda **melewati program keylogger** dari menyimpan data pribadi Anda, seperti: *Nama Pengguna dan Kata Sandi* pada browser Mozilla Firefox.

Pada dasarnya, ini memberi Anda **keyboard virtual** yang akan membantu Anda memasukkan kredensial Anda di browser Firefox tanpa direkam oleh program keylogger.

Program keyboard virtual ini memiliki *dua mode yang dapat Anda gunakan untuk memasukkan data* saat bekerja di Mozilla Firefox. Namun pertama-tama, Anda harus *mengaktifkannya* dengan menekan *Hot-Key-nya:* **Ctrl+Alt+k** . Ini akan menampilkan keyboard virtual di bawah kolom tempat Anda ingin mengetik di Firefox.

Sekarang dengan keyboard ini, Anda dapat memilih **metode input keyboard atau mouse** .

*Metode masukan tetikus* terlalu mudah digunakan dan Anda hanya perlu **mengarahkan penunjuk tetikus ke tombol yang diinginkan** di papan ketik virtual. Kemudian *secara otomatis akan menekan dan memasukkan huruf/karakter* pada kolom yang diinginkan.

*Metode input keyboard* agak rumit. Pada mode ini terdapat **Shadow Key dengan Real Keynya** *(kanan atas)* . Anda harus *mencari dan menekan tombol bayangan yang mewakilinya dari keyboard* . Meskipun ini merupakan hal yang sibuk untuk dilakukan, keylogger akan mencatat tombol bayangan yang ditekan dan bukan kunci sebenarnya.

Anda bahkan dapat menggunakan *metode input keyboard dari mouse Anda* daripada menekan Shadow Keys dari keyboard. Untuk ini, Anda harus mengaktifkan opsi **Keduanya** .

Izinkan saya memberi tahu Anda bahwa *Add-on gratis ini hanya akan berfungsi* untuk memasukkan **Nama Pengguna, Kata Sandi** , dan **URL/Teks** *(bilah alamat)* . Selain bidang ini, Add-On ini tidak dapat digunakan di tempat lain.

Jika Anda ingin menggunakan browser lain selain Firefox dan masih ingin menggunakan alat jenis ini, saya sarankan Anda menginstal beberapa program [keyboard virtual](https://listoffreeware.com/list-best-free-screen-keyboards/ "Daftar Keyboard Layar Gratis Terbaik Untuk Windows") di sistem Anda, yang menyediakan layanan serupa.
