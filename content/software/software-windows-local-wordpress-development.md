## XAMPP

**XAMPP** adalah perangkat lunak pengembangan WordPress lokal open source gratis yang populer untuk Windows. Perangkat lunak ini adalah paket semua perangkat lunak penting yang Anda perlukan untuk menjalankan WordPress yaitu **Apache, MariaDB, PHP,** dan **Perl** . Perangkat lunak ini secara otomatis menginstal dan mengkonfigurasi semua perangkat lunak bawaan. Namun, ia tidak menginstal atau mengatur WordPress seperti beberapa perangkat lunak serupa lainnya. Oleh karena itu, Anda perlu mengunduh, menginstal, dan mengatur WordPress secara manual di komputer Anda. Untuk melakukan itu, pertama-tama, unduh pengaturan **[WordPress](https://wordpress.org/download/ "Unduh WordPress")** . Setelah itu, ekstrak setup WordPress yang sudah diunduh dan paste ke folder **C:** > **xampp** > **htdocs** . Sekarang, Anda dapat memulai proses penyiapan.

### Cara setting WordPress menggunakan XAMPP:

* Luncurkan **XAMPP** dan mulai **Apache** dan **MySQL** dari antarmukanya dan buka browser web.
* Setelah itu, cari **localhost/wordpress** di browser Anda. Anda akan segera mendapatkan layar pengaturan WordPress yang meminta Anda untuk mengatur database dengan memberikan *Nama Database, Nama Pengguna Database, Host Database, Kata Sandi Database,* dll. Untuk melakukan itu, cukup ketik dan cari localhost/phpmydamin di browser web Anda untuk buka **halaman PHPMyAdmin** .
* Dari halaman PHPMyAdmin, buat database baru dengan menekan **tombol New** dan dengan memberikan **nama database** .
* Setelah itu, buka kembali layar pengaturan awal WordPress dan tekan tombol **Let's Go** untuk berpindah ke halaman pengaturan situs web.
* Di halaman ini, Anda perlu memberikan informasi seperti **Judul Situs, Nama Pengguna, Kata Sandi,** dan **Alamat Email** .
* Terakhir, klik **tombol Instal WordPress** untuk memulai proses instalasi.

Setelah instalasi WordPress, Anda dapat mengunjungi halaman Pengembangan WordPress dengan memasukkan **localhost/wordpress** di browser web Anda.

Perangkat lunak ini tidak terlalu ramah pengguna, tetapi menawarkan kontrol lebih besar atas setiap komponennya. Misalnya- Anda dapat dengan mudah memulai atau menghentikan layanan individual XAMPP kapan saja, seperti *Apache Server, MySQL, Tomcat,* dll. Untuk menjalankan satu situs WordPress, ini cukup bagus, tetapi untuk menjalankan beberapa situs WordPress, Anda perlu melakukan pengaturan cukup banyak konfigurasi.

### Pikiran Terakhir:

Ini adalah perangkat lunak pengembangan WordPress yang sangat fleksibel yang memberikan banyak kontrol atas layanannya. Namun, ini lebih cocok untuk pengguna tingkat lanjut karena memberikan ruang untuk mengubah banyak parameter untuk mendapatkan hasil yang diinginkan.

## MAMP

**MAMP** adalah software pengembangan WordPress lokal gratis berikutnya untuk Windows. MAMP adalah singkatan dari **My Apache** , **MySQL** , dan **PHP** . Ini mirip dengan XAMPP, yang juga dilengkapi dengan beberapa layanan yang diperlukan untuk melakukan pengembangan WordPress dan membuat situs web WordPress. Itu tidak disertakan dengan WordPress seperti XAMPP, oleh karena itu Anda perlu mengunduh dan menginstal WordPress secara manual ke perangkat lunak ini. Sebelum melakukan proses setup, Anda perlu menginstal MAMP dan mendownload setup **[WordPress .](https://wordpress.org/download/ "Unduh WordPress")** Setelah itu ekstrak folder WordPress dan paste ke folder **C:/MAMP/htdocs** . Anda sekarang dapat mulai menyiapkan WordPress dengan perangkat lunak ini.

### Cara mengatur WordPress menggunakan MAMP:

* Luncurkan MAMP dan mulai **Server Apache** dan **Server MySQL** .
* Setelah itu, klik **Open WebStart Page** untuk melihat dashboard MAMP di browser default Anda.
* Sekarang, klik **tautan PhpMyAdmin** yang ada di halaman selamat datangnya dan konfigurasikan database dengan memberikan *nama database* .
* Terakhir, masukkan **Localhost/wordpress** pada bilah pencarian browser dan tekan Enter untuk melihat *halaman otentikasi WordPress* . *Nama pengguna* dan *kata sandi* default diberikan di halaman Selamat Datang MAMP.
* Setelah mengirimkan kredensial login yang benar, Anda dapat melihat **Halaman Pengembangan WordPress** .

### Fitur Utama MAMP:

* Ini memungkinkan Anda menjalankan situs pengembangan WordPress pada berbagai versi PHP.
* Ini mendukung dua bahasa tambahan yaitu **Pearl** dan **Python** .
* Anda dapat mengatur situs WordPress lokal khusus.
* Ini memungkinkan Anda untuk mengatur lingkungan berbasis **PHP, Apache,** dan **MySQL .**
* Muncul dengan dasbornya sendiri untuk memeriksa ringkasan dan informasi umum seperti status server, layanan aktif, dll.

### Keterbatasan:

MAMP versi gratis ini memiliki berbagai keterbatasan seperti hanya tersedia dua versi PHP, hanya dapat meng-host satu situs web dalam satu waktu, kurangnya DNS Dinamis, dll. Untuk menghilangkan semua keterbatasannya, Anda perlu membeli versi berbayar dari perangkat lunak ini.

### Kesimpulan:

Ini adalah perangkat lunak lain yang layak dengan fitur-fitur penting yang mendukung pengembangan WordPress lokal. Selain itu, ia juga menawarkan fleksibilitas seperti *memulai/menghentikan situs web* , *mengaktifkan/menonaktifkan Server Apache* , dll.

## AmanWAMP

Ini pada dasarnya adalah perangkat lunak hosting web yang sangat aman yang juga dapat digunakan sebagai perangkat lunak pengembangan WordPress. Perangkat lunak ini terdiri dari lima layanan berbeda yaitu **Apache, PHP, MySQL Server, Filezilla FTP Server,** dan **Mercury/32 Mail-Server** . Untuk bekerja dengan WordPress, Anda hanya memerlukan *layanan Apache, PHP, dan MySQL Server-* nya . Dari antarmukanya, Anda dapat dengan mudah memulai atau menghentikan layanan apa pun kapan saja, yang memberikan tingkat fleksibilitas tinggi bagi penggunanya. Namun, sebelum menggunakan layanan ini untuk menjalankan pengaturan, Anda perlu mengonfigurasi berbagai pengaturan dan menginstal WordPress ke perangkat lunak ini.

### Cara mengkonfigurasi SecureWAMP untuk memulai pengembangan WordPress:

* Langkah pertama adalah menginstal **SecureWAMP** ke sistem Anda.
* Setelah instalasi, buka antarmukanya dan mulai **Apache, PHP,** dan **MySQL Server** .
* Sekarang, klik tombol *konfigurasi server MySQL* dan pilih opsi **PHPMyAdmin** untuk membuka halaman PHPMyAdmin di browser web default Anda.
* Dari halaman PHPMyAdmin, *buat database baru* dan *atur nama database dan kata sandi* .

* Setelah mengonfigurasi semua pengaturan, tekan **tombol Let's Go** untuk memulai Instalasi WordPress.
* Setelah instalasi berhasil diselesaikan, Anda akan dapat mengakses WordPress dengan mengetikkan *localhost/WordPress* di browser web Anda dan memulai proses pengembangan situs web atau blog.

Sebelum memulai pengembangan WordPress, Anda perlu mengkonfigurasi dan mengatur perangkat lunak ini. Anda dapat mengikuti langkah-langkah di bawah ini untuk menyiapkan perangkat lunak ini dengan benar untuk pengembangan situs WordPress.

### Cara mengatur Perangkat Lunak Pengembangan WordPress lokal ini:

* Luncurkan perangkat lunak ini dan mulai Server dari **menu Servernya** .
* Setelah itu, unduh WordPress dan ekstrak ke **Folder WWW** . Anda dapat langsung mengakses folder ini dengan mengklik *opsi folder WWW* .
* Sekarang, cari **localhost/WordPress** di browser web Anda.
* Halaman WordPress akan terbuka, di mana Anda perlu memberikan *nama database, kata sandi database,* dll., untuk membuat koneksi dengan database. Semua detail yang terkait dengan database dapat dilihat dari *file readme* yang disertakan dengan software ini.
* Setelah membuat koneksi, tekan tombol **Lets Go** untuk memulai proses instalasi WordPress.
* Terakhir, masukkan **localhost/wordpress** di browser Anda untuk meluncurkan antarmuka utama WordPress dan mulai mengembangkan situs, blog, dll.

### Kesimpulan:

Ini adalah perangkat lunak pengembangan WordPress lokal standar lainnya yang melaluinya Anda dapat menjalankan WordPress dengan lancar. Plus, itu juga dapat meng-host beberapa situs web lokal dengan mudah.
